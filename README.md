# AmneziaWG для ImmortalWrt (Ядро 6.12.103)

Готовые пакеты ядерного модуля (`kmod-amneziawg`) AmneziaWG, собранные специально под **ImmortalWrt 25.12.2** с версией ядра **6.12.103** для архитектуры **ramips/mt7621** (Xiaomi Mi Router 3G и аналогичные).

## Быстрая установка одной командой по SSH:
Скопируйте код ниже, вставьте в консоль роутера и нажмите Enter:
```bash
cd /tmp && wget https://github.com... (вставьте сюда команду из Пункта 2)
```
